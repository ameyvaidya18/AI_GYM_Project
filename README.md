# AI_GYM_Project

The **AI Gym Trainer** is an intelligent computer vision application that acts as a virtual personal trainer. Using camera-based pose estimation via **Python, OpenCV, and MediaPipe**, it automatically tracks body posture, counts repetitions, and detects form errors during exercises like push-ups, squats, and bicep curls.
Designed as a low-cost alternative to a physical trainer, the platform delivers real-time safety feedback, personalized workout guidance, and performance tracking through an interactive web interface.

Key Features:
🏋️ Exercise detection
🔢 Automatic repetition counting
📷 Real-time camera-based pose detection
✅ Correct/incorrect posture detection
🤖 AI-based workout guidance
📊 Workout and performance tracking
🎯 Personalized exercise feedback
💻 User-friendly web interface

Technologies Used:
Python
OpenCV
MediaPipe / Pose Estimation
Machine Learning / AI
